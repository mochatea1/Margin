⚡ 5-MINUTE SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Copy Files to Your Project
─────────────────────────────────────────
  Copy these 3 files to your VSCode project folder:
    ✓ index.html
    ✓ app.py
    ✓ requirements.txt


STEP 2: Update Database Connection
─────────────────────────────────────────
  Edit app.py line 11:
    DB_CONNECTION_STRING = 'Driver={ODBC Driver 17 for SQL Server};
                          Server=YOUR_SERVER;
                          Database=YOUR_DB;
                          Trusted_Connection=yes;'


STEP 3: Install Dependencies
─────────────────────────────────────────
  Terminal:
    $ pip install -r requirements.txt


STEP 4: Start Flask Backend (Terminal 1)
─────────────────────────────────────────
  Terminal:
    $ python app.py
  
  Output:
    * Running on http://localhost:5000


STEP 5: Serve Frontend (Terminal 2)
─────────────────────────────────────────
  Terminal:
    $ python -m http.server 8000
  
  Output:
    Serving HTTP on http://localhost:8000


STEP 6: Open Dashboard
─────────────────────────────────────────
  Browser:
    http://localhost:8000

  ✅ Dashboard loads!

📊 API ENDPOINTS (Flask Backend)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Base URL: http://localhost:5000/api

Tài khoản:
  GET    /taikhoan              Get all accounts
  GET    /taikhoan/<matk>       Get account detail
  POST   /taikhoan              Create account
  PUT    /taikhoan/<matk>       Update account
  DELETE /taikhoan/<matk>       Delete account

Chứng khoán:
  GET    /chungkhoan            Get all securities
  GET    /chungkhoan/<mack>     Get security detail
  POST   /chungkhoan            Create security
  PUT    /chungkhoan/<mack>     Update security
  DELETE /chungkhoan/<mack>     Delete security

Vị thế:
  GET    /vithe                 Get all positions
  GET    /vithe/<id>            Get position detail
  POST   /vithe                 Create position
  PUT    /vithe/<id>            Update position
  DELETE /vithe/<id>            Delete position

Sổ lệnh:
  GET    /lenhgd                Get all orders
  GET    /lenhgd/<malenhgd>     Get order detail
  POST   /lenhgd                Create order
  PUT    /lenhgd/<malenhgd>     Update order
  DELETE /lenhgd/<malenhgd>     Delete order
